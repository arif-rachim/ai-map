A. Iframe tanpa coding

Tempelkan satu tag ini ke halaman web mana pun di jaringan kantor:

<iframe src="{{BASE}}/embed" style="width:100%; height:600px; border:0" title="Peta"></iframe>

Lalu tambahkan parameter setelah ?, dipisah &. Contoh: /embed?center=46.67,24.71&zoom=10&controls=none.

controls=none = peta murni. controls=-draw,-status = semua kecuali itu. controls=draw,-draw.milsymbol = semua tool gambar kecuali simbol militer.

B. Developer JavaScript

B0. Memuat SDK

SDK disajikan server ini — tidak perlu npm atau internet.

<script src="{{BASE}}/sdk/aimap-sdk.js"></script>   <!-- global: AiMap -->

// atau sebagai ES module
import { AiMapEmbed, AiMapClient, addDrawings } from '{{BASE}}/sdk/aimap-sdk.mjs';

Tipe TypeScript: /sdk/aimap-sdk.d.ts · Referensi REST: /api/v1/docs

B1. Membuat peta embed

<div id="peta" style="height:600px"></div>
<script src="{{BASE}}/sdk/aimap-sdk.js"></script>
<script>
  const map = AiMap.AiMapEmbed.create('#peta', {
    baseUrl: '{{BASE}}',
    center: [46.6753, 24.7136], zoom: 11,
    controls: ['search', 'zoom', 'layers'],   // sama dengan parameter URL
    readonly: true,
  });
  await map.ready;
  map.on('click', (e) => console.log('klik', e.lat, e.lon, e.markerId, e.featureId));
</script>

B2. Peta MapLibre milik sendiri

Basemap, terrain, dan gambar bersama dari server ini di peta aplikasi Anda. Contoh lengkap: maplibre.html.

<link rel="stylesheet" href="{{BASE}}/vendor/maplibre/maplibre-gl.css" />
<div id="peta" style="height:600px"></div>
<script type="module">
  import * as maplibregl from '{{BASE}}/vendor/maplibre/maplibre-gl.mjs';
  import { AiMapClient, addDrawings } from '{{BASE}}/sdk/aimap-sdk.mjs';

  const client = new AiMapClient('{{BASE}}');
  const map = new maplibregl.Map({
    container: 'peta',
    style: client.styleUrl({ theme: 'light', lang: 'en', terrain: 'hillshade' }),   // none | hillshade | 3d
    center: [46.67, 24.71], zoom: 9,
  });
  map.on('load', async () => {
    const gambar = await addDrawings(map, client);   // live, sama persis dengan aplikasi utama
    map.on('click', gambar.layerIds, (e) => alert(e.features[0].properties.name));
  });
  map.on('click', async (e) => console.log(await client.elevation(e.lngLat.lng, e.lngLat.lat), 'm'));
</script>

B3. Backend dan bahasa lain

// Node.js 18+ — salin {{BASE}}/sdk/aimap-sdk.mjs ke proyek Anda
import { AiMapClient } from './aimap-sdk.mjs';
const client = new AiMapClient('{{BASE}}');
const [layer] = await client.layers();
await client.createFeature({ layerId: layer.id, kind: 'point', name: 'Checkpoint 4',
  geometry: { type: 'Point', coordinates: [46.7, 24.7] } });
client.subscribe((m) => console.log(m.type), { onOpen: () => console.log('terhubung') });
# Bahasa apa pun lewat HTTP
curl '{{BASE}}/api/v1/search?q=Riyadh&limit=5'
curl '{{BASE}}/api/v1/elevation?lon=42.5053&lat=18.2164'
curl -o layer.kml '{{BASE}}/api/v1/layers/<id>/export.kml'
