A. Iframe without coding

Paste this one tag into any web page on the office network:

<iframe src="{{BASE}}/embed" style="width:100%; height:600px; border:0" title="Map"></iframe>

Then add parameters after ?, separated by &. Example: /embed?center=46.67,24.71&zoom=10&controls=none.

B. JavaScript developers

B0. Loading the SDK

The SDK is served by this server — no npm or internet needed.

<script src="{{BASE}}/sdk/aimap-sdk.js"></script>   <!-- global: AiMap -->

// or as an ES module
import { AiMapEmbed, AiMapClient, addDrawings } from '{{BASE}}/sdk/aimap-sdk.mjs';

TypeScript types: /sdk/aimap-sdk.d.ts · REST reference: /api/v1/docs

B1. Creating an embedded map

<div id="map" style="height:600px"></div>
<script src="{{BASE}}/sdk/aimap-sdk.js"></script>
<script>
  const map = AiMap.AiMapEmbed.create('#map', {
    baseUrl: '{{BASE}}',
    center: [46.6753, 24.7136], zoom: 11,
    controls: ['search', 'zoom', 'layers'],   // same as the URL parameters
    readonly: true,
  });
  await map.ready;
  map.on('click', (e) => console.log('click', e.lat, e.lon, e.markerId, e.featureId));
</script>

B2. Your own MapLibre map

The basemap, terrain and shared drawings from this server on your application's map. Full example: maplibre.html.

<link rel="stylesheet" href="{{BASE}}/vendor/maplibre/maplibre-gl.css" />
<div id="map" style="height:600px"></div>
<script type="module">
  import * as maplibregl from '{{BASE}}/vendor/maplibre/maplibre-gl.mjs';
  import { AiMapClient, addDrawings } from '{{BASE}}/sdk/aimap-sdk.mjs';

  const client = new AiMapClient('{{BASE}}');
  const map = new maplibregl.Map({
    container: 'map',
    style: client.styleUrl({ theme: 'light', terrain: 'hillshade' }),   // none | hillshade | 3d
    center: [46.67, 24.71], zoom: 9,
  });
  map.on('load', async () => {
    const drawings = await addDrawings(map, client);   // live, exactly like the main app
    map.on('click', drawings.layerIds, (e) => alert(e.features[0].properties.name));
  });
  map.on('click', async (e) => console.log(await client.elevation(e.lngLat.lng, e.lngLat.lat), 'm'));
</script>

B3. Backends and other languages

// Node.js 18+ — copy {{BASE}}/sdk/aimap-sdk.mjs into your project
import { AiMapClient } from './aimap-sdk.mjs';
const client = new AiMapClient('{{BASE}}');
const [layer] = await client.layers();
await client.createFeature({ layerId: layer.id, kind: 'point', name: 'Checkpoint 4',
  geometry: { type: 'Point', coordinates: [46.7, 24.7] } });
client.subscribe((m) => console.log(m.type), { onOpen: () => console.log('connected') });
# Any language over HTTP
curl '{{BASE}}/api/v1/search?q=Riyadh&limit=5'
curl '{{BASE}}/api/v1/elevation?lon=42.5053&lat=18.2164'
curl -o layer.kml '{{BASE}}/api/v1/layers/<id>/export.kml'

Troubleshooting

SymptomFix
Empty iframeOpen /api/v1/health; run aimapctl status on the server
map.ready never resolvesbaseUrl must exactly match the server address (scheme, host, port)
"Map is not ready yet"Run commands after await map.ready
"Unknown controls: …"Check the component names in the controls table
"Version conflict"Another user changed the object; fetch it again and retry
An HTTPS page blocks an HTTP mapUse the same scheme for the page and the map server
Markers disappear after a reloadsetMarkers is temporary by design; use addFeature for permanent data
