1. Server

Base URL of the map server. Locally: http://localhost:8080; production: https://map.jac.mil.ae.

2. Admin (for writing)

Reading needs nothing. Creating/editing layers and drawings needs either the admin password (gives a 12 h session) or the ADMIN_API_TOKEN (aimapctl admin on the server). Stored in this browser only.

Option A: password

Option B: API token

Pages

REST APIEvery endpoint with one click: search, airports, elevation, layers, features, import/export, auth. Shows status, time and request id.
Embed (iframe)The full map in an iframe, driven by the SDK: load layers, admin token, save pins, markers, tools, events.
Own MapLibre mapYour own MapLibre GL map using the server's style, tiles and live drawings of chosen layers; click for elevation.
Real-timeWebSocket event stream: open it next to the map and watch changes arrive.
Traffic testSends bursts of requests and shows latency, to check the access log (aimapctl access).
